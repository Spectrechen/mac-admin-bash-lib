# CleverShare Vendor Notes

## Vendor Information
- **Vendor:** Clevertouch Technologies (now part of Boxlight Corporation)
- **Product:** CleverShare - Wireless screen sharing to Clevertouch panels
- **Website:** https://www.clevertouch.com/clevershare2g
- **License:** Free to download
- **Installomator label:** clevershare2
- **Installer type:** dmg

## Download URLs
- **Download page:** https://www.clevertouch.com/clevershare2g
- **Latest version:** N/A (free app, no versioned releases documented)
- **App location:** /Applications/Clevershare.app

## Version Detection
No versioned releases documented for CleverShare. The app is free and updated silently via the vendor website. Returns "latest" as the version string.

## Installation
- The vendor website provides a direct DMG download.
- Requires root privileges for /Applications install.
- Designed for use with Clevertouch interactive touchscreens.
- The computer and Clevertouch must be on the same wireless network.

## Update
No vendor-provided automatic update mechanism. Reinstall the latest version to update.

## Uninstall
Remove app bundle and associated support files:
- /Applications/Clevershare.app
- ~/Library/Application Support/Clevershare
- ~/Library/Preferences/com.clevertouch.Clevershare.plist
- ~/Library/Caches/com.clevertouch.Clevershare
