# Vendor Notes: ChronoAgent (chronoagent)

## Overview
ChronoAgent is a virtual instrument/effect/plugin from Cherry Audio (except ChronoAgent from Econ Technologies).

## Vendor Sources

- Product page: https://www.econtechnologies.com/chronoagent/overview.html
- Store page: https://chronoagent.macupdate.com/
- Version history: https://www.econtechnologies.com/downloads/downloads.html
- Direct installer: https://www.econtechnologies.com/downloads/ChronoAgent.dmg

## Package Information

- Package ID: `com.econtechnologies.ChronoAgent`
- Team ID: `unknown`
- Installer type: `pkg`

## Install/Update/Uninstall

- Install: Download DMG from installer URL, mount, copy .app to /Applications/ (or use pkgutil for pkg installers)
- Update: Updates available via store page download; install() fetches latest.
- Uninstall: Remove package receipt `com.econtechnologies.ChronoAgent` via `pkgutil --forget`

## Notes

- ChronoAgent is a background utility by Econ Technologies for remote file sharing.
- No window UI; runs in background.
- Used with ChronoSync or InterConneX.
